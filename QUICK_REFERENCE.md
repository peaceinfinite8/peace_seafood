## ⚡ QUICK ACTIONS

### **Input Stok Masuk**
```
Stok → Stok Masuk → + Tambah
↓
Isi: Tanggal, Supplier, Produk, Jumlah, Harga
↓
Simpan
```

### **Buat Nota Penjualan**
```
Penjualan → Buat Nota
↓
Pilih Pelanggan → + Tambah Produk
↓
Isi jumlah → Pilih Metode Bayar
↓
Simpan & Cetak
```

### **Catat Timbangan**
```
Stok → Timbangan → + Timbang
↓
Pilih Produk → Berat Kotor & Bersih
↓
Foto (opsional) → Simpan
↓
Tunggu Checker Approve
```

### **Bayar Piutang**
```
Keuangan → Piutang
↓
Klik nama pelanggan → Klik Bayar
↓
Isi jumlah → Upload bukti (jika transfer)
↓
Simpan
```

## 🆘 TROUBLESHOOTING CEPAT

| Problem | Solusi |
|---------|--------|
| Tidak bisa login | Lupa password → Reset via email |
| Stok tidak update | Refresh halaman (F5) |
| Nota tidak cetak | Allow pop-up di browser |
| Upload file gagal | Cek ukuran < 5MB & format JPG/PNG/PDF |
| Masa aktif habis | Upload bukti transfer + hubungi admin |
