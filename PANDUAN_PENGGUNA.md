## 🎯 TENTANG SISTEM

Peace Seafood WMS adalah sistem manajemen gudang berbasis cloud yang dirancang khusus untuk bisnis seafood. Sistem ini membantu Anda mengelola:

- ✅ Stok barang masuk dan keluar
- ✅ Penjualan dan nota
- ✅ Penitipan barang
- ✅ Retur dari pelanggan
- ✅ Laporan keuangan
- ✅ Tim dan karyawan

**Akses Sistem:** https://peaceseafood.com

## 💡 FITUR UTAMA - CARA PAKAI

### **1. INPUT STOK MASUK**

**Tujuan:** Catat barang baru dari supplier

**Langkah:**
1. Menu **Stok** → **Stok Masuk**
2. Klik **+ Tambah Stok Masuk**
3. Isi form:
   - Tanggal terima
   - Supplier
   - Pilih produk
   - Jumlah (kg/pcs)
   - Harga beli per unit
4. **Simpan**

**Tips:**
- Input segera setelah barang datang
- Cek kualitas sebelum input
- Foto barang untuk dokumentasi

---

### **2. BUAT NOTA PENJUALAN**

**Tujuan:** Catat transaksi penjualan

**Langkah:**
1. Menu **Penjualan** → **Buat Nota**
2. Pilih/tambah pelanggan
3. Tambah produk:
   - Pilih produk dari daftar
   - Isi jumlah
   - Harga otomatis muncul (bisa diedit)
4. Pilih metode pembayaran:
   - Cash
   - Transfer
   - Tempo (piutang)
5. **Simpan & Cetak**

**Tips:**
- Untuk tempo, isi tanggal jatuh tempo
- Bisa save as draft jika belum selesai
- Cetak nota untuk pelanggan

---

### **3. TIMBANGAN (untuk Seafood)**

**Tujuan:** Catat hasil timbangan real-time

**Langkah:**
1. Menu **Stok** → **Timbangan**
2. **+ Timbang Baru**
3. Isi:
   - Pilih produk
   - Berat kotor (sebelum dibersihkan)
   - Berat bersih (siap jual)
   - Grade/kualitas
   - Foto (opsional)
4. **Simpan**

**Tips:**
- Timbang segera setelah terima
- Catat susut untuk akurasi
- Checker akan verifikasi

---

### **4. PENITIPAN**

**Tujuan:** Kelola barang titipan dari pemasok

**Langkah:**
1. Menu **Penitipan** → **+ Tambah Titipan**
2. Isi data:
   - Pemasok
   - Produk
   - Jumlah
   - Harga jual (kesepakatan)
   - Komisi (%)
3. **Simpan**

**Cara Jual:**
- Buat nota seperti biasa
- Pilih produk titipan
- Sistem otomatis hitung komisi

**Pengembalian:**
- Jika tidak laku, bisa dikembalikan
- Klik **Kembalikan** pada data titipan
- Isi jumlah yang dikembalikan

---

### **5. RETUR**

**Tujuan:** Catat barang retur dari pelanggan

**Langkah:**
1. Menu **Retur** → **+ Tambah Retur**
2. Pilih nota asli (dari riwayat)
3. Pilih item yang diretur
4. Isi:
   - Jumlah retur
   - Alasan
   - Foto bukti (opsional)
5. Pilih metode refund:
   - Uang kembali
   - Tukar barang
   - Potong piutang
6. **Simpan**

**Tips:**
- Cek kondisi barang retur
- Foto untuk dokumentasi
- Stok otomatis bertambah

---

### **6. KELOLA PIUTANG**

**Tujuan:** Monitor dan tagih piutang pelanggan

**Cara Lihat Piutang:**
1. Menu **Keuangan** → **Piutang**
2. Lihat daftar pelanggan + jumlah piutang
3. Klik nama untuk detail per nota

**Cara Bayar Piutang:**
1. Klik **Bayar** pada nota
2. Isi:
   - Jumlah bayar (bisa sebagian/lunas)
   - Metode (cash/transfer)
   - Bukti transfer (foto)
3. **Simpan**

**Aging Piutang:**
- 🟢 Belum jatuh tempo
- 🟡 Jatuh tempo 1-7 hari
- 🟠 Jatuh tempo 8-30 hari
- 🔴 Jatuh tempo > 30 hari

---

### **7. LAPORAN**

**Tujuan:** Analisis bisnis

**Jenis Laporan:**

**📊 Laporan Penjualan**
- Pilih periode (hari/bulan)
- Lihat total omzet
- Breakdown per produk
- Download PDF/Excel

**💰 Laba Rugi**
- Otomatis hitung:
  - Pendapatan
  - Harga pokok penjualan
  - Laba kotor/bersih
- Per periode

**📦 Stok Realtime**
- Lihat stok semua produk
- Warning stok menipis
- Nilai stok (modal)

**👥 Performa Karyawan**
- Total transaksi per karyawan
- Omzet yang dihasilkan

## 🆘 TROUBLESHOOTING

### **Problem: Tidak Bisa Login**

**Solusi:**
1. Cek email/password (huruf besar-kecil)
2. Klik **Lupa Password** untuk reset
3. Cek email untuk link reset
4. Jika tidak terima email, cek folder spam
5. Hubungi admin jika masih gagal

### **Problem: Stok Tidak Update**

**Solusi:**
1. Refresh halaman (F5)
2. Cek koneksi internet
3. Cek apakah transaksi tersimpan
4. Lihat activity log untuk konfirmasi

### **Problem: Nota Tidak Bisa Dicetak**

**Solusi:**
1. Allow pop-up di browser
2. Cek printer settings
3. Download PDF jika print gagal
4. Cek browser support (Chrome/Firefox recommended)

### **Problem: Upload File Gagal**

**Solusi:**
1. Cek ukuran file (max 5MB)
2. Format harus JPG/PNG/PDF
3. Cek koneksi internet
4. Compress file jika terlalu besar

### **Problem: Masa Aktif Habis**

**Solusi:**
1. Upload bukti transfer di form yang muncul
2. Hubungi admin via WhatsApp
3. Tunggu approval (biasanya < 1 jam)
4. Akses akan otomatis pulih setelah approved
